Профиль анализа

Для снижения когнитивной нагрузки пользователю предлагаются готовые профили запуска с понятными сценариями применения.

Быстрый Статический анализ и базовая проверка зависимостей проекта.
Полный Все доступные подсистемы анализа и сохранение артефактов.
Пользовательский Ручной выбор отдельных модулей и параметров выполнения.

Выбор подсистем

Опции сгруппированы по смыслу и показывают текущее состояние каждой проверки.

Static analysis Сбор метрик качества, поиск code smells и нарушений стиля.
Dynamic analysis Сбор информации о выполнении кода и поведении модулей во время запуска.
Tests & coverage Запуск тестов, формирование отчета о покрытии и проверка успешности сценариев.
Security scan Анализ зависимостей и выявление потенциально небезопасных конструкций.
Architecture scan Оценка связности модулей, coupling, cohesion и циклических зависимостей.
Сохранение артефактов Сохранение логов, отчетов и промежуточных результатов для последующего просмотра.

Параметры выполнения

Дополнительные настройки позволяют уточнить среду выполнения и формат итоговых результатов.
